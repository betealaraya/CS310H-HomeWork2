# CS310H-HomeWork2
## About
Unreal Engine 5.8.2 with the First Person template.

## What I Made

**Main Menu**
- Start Game button
- Quit Game button

**Level 1 and Level 2**
- Two playable levels with different layouts
- Targets that lose health when shot and disappear when destroyed
- Hazards that damage the player
- Automatic level transitions when all targets are destroyed

**Ammo System**
- Limited ammunition
- Ammo counter displayed on screen
- Shooting stops when ammo reaches zero

**Pickups**
- Ammo pickups
- Health pickups
